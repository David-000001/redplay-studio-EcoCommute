# UM EcoCommute — A Smart Campus Mobility and Climate Awareness Application

RedPlay Studio · WIA2007 Mobile Application Development · Universiti Malaya · Tutorial Group 9

UM students log a commute, compare transport modes for the same distance and see how their choices affect indicative CO₂e. The proposed app links personal history to climate lessons, quizzes and challenges under SDG 13, Target 13.3. An administrator sees anonymized mobility summaries.

## Development status

The Java/XML Android foundation, Firebase account access and local emulator workflow are available. Journey logging, emissions comparisons, learning and aggregate reporting are planned modules. The source namespace is `com.example.um_ecocommute`. The registered Android application ID and Firebase project ID are retained for existing accounts and configuration. Previous Firebase verification covers the account foundation only.
