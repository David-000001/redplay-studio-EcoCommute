# Commuting estimates and SDG 13.3

For a mode with a documented passenger-kilometre factor, multiply journey distance (km) by that factor (kg CO₂e/passenger-km). For a vehicle-kilometre factor, document how occupancy is handled before comparing it with passenger-kilometre figures. Save the factor version so a later revision does not silently rewrite history.

Compare alternatives at the same distance and boundary. State whether a factor covers direct travel or a wider lifecycle. Distinguish an unavailable estimate from zero. A difference between scenarios is illustrative. Do not report it as measured carbon savings. The team must select, cite and review factors before presenting numerical results.

Measure education with quiz responses and challenge participation. Record the sample size and limitations of any before/after comparison.
